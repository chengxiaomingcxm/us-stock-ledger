# 持仓账本

这是我自己用的美股持仓账本，主要用来记买卖、看持仓成本和收益。做成了中文 iPhone App，数据留在本机，不用注册账号。

目前是 **1.23**，支持 iOS 16 及以上。

[下载安装包](https://github.com/chengxiaomingcxm/us-stock-ledger/releases/tag/v1.23.0) · [使用帮助](HELP.md) · [更新记录](CHANGELOG.md)

## 能做什么

- 记录买入、卖出、手续费和备注，自动计算持仓成本与收益。
- 查看每日收益日历和历史曲线。
- 使用默认收盘行情，也可以在设置里换成 Finnhub 或自定义 API。
- 导出备份、恢复账本，或者先用示例模式看看。

目前只做美元美股和 ETF 记账，不连接券商，也不处理分红、拆股、做空和期权。

## 1.23 更新

这次主要新增了外观与提醒，并让记账更快一点。

- 设置里可选择跟随系统 / 浅色 / 深色外观，以及绿涨红跌或红涨绿跌的涨跌颜色，并设置备份提醒。
- 行情 API 密钥在 iPhone 上改存系统钥匙串，更安全，也不进入账本备份。
- 卖出时可一键填一半或全部，股票代码有最近下拉，手续费自动沿用上一笔；保存后还能撤销刚才新增的交易。

之前的卡片首页、金额隐藏、行情 API 设置、收益日历和备份功能都保留。详细内容见 [1.23 升级说明](releases/v1.23.0.md)。

## 安装和备份

Release 里的 IPA 没有签名，需要用自己的 Apple 账号签名后安装，例如使用 Sideloadly。

**升级前先导出完整备份，再用原签名账号和应用标识覆盖安装，不要先卸载旧版。** 应用标识是 `com.personal.stockledger`。

账本不会自动同步到其他设备，卸载也会删除本机数据，记得把备份存到应用外。API 密钥不包含在账本备份里，换设备后要重新填写。

行情是否及时取决于数据源和订阅权限。最新报价用于当前估值，每日收益日历仍用收盘历史。配置方法见 [API 设置说明](API-SETTINGS.md)。

## 本地运行

项目用 TypeScript、Vite 和 Capacitor 开发。安装 Node.js 24 和 pnpm 11.19.0 后：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

浏览器里的数据与 iPhone 分开保存。iOS 安装包通过仓库的 GitHub Actions 编译，也可以在 Mac 上使用 Xcode 构建。

计算口径和旧版兼容问题，分别放在 [收益说明](DAILY-RETURNS.md) 和 [数据兼容说明](DATA-COMPATIBILITY.md)。
