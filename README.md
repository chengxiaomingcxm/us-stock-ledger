# 持仓账本

这是我自己用的美股持仓账本，主要用来记买卖、看持仓成本和收益。做成了中文 iPhone App，数据留在本机，不用注册账号。

当前发布版本是 **1.26**，支持 iOS 16 及以上。1.26 发布源码保留在对应版本标签中。

**2.0 正在开发中**：界面改用 SwiftUI 原生实现（同样的四个页面与记账流程），功能以对齐 1.26 为目标，原生代码已进入 `main`，当前为 2.0.0 build 3 的验证构建，尚未替换 1.26 正式 Release。2.0 使用独立的账本格式，不读取 1.x 数据，升级前请用 1.26 导出备份。进展见 [更新记录](CHANGELOG.md)。

[下载 1.26](https://github.com/chengxiaomingcxm/us-stock-ledger/releases/tag/v1.26.0) · [使用帮助](HELP.md) · [更新记录](CHANGELOG.md)

## 能做什么

- 记录买入、卖出、手续费和备注，自动计算持仓成本与收益。
- 首页区分今日盈亏（上一收盘、当前价格加当天买卖）与持有收益，缺失行情显示待补全。
- 查看每日收益日历和历史曲线。
- 交易页按日期区间、买卖类型和关键字筛选，汇总范围内手续费与已实现收益。
- 现金账本记录期初余额、入金、出金、手动分红和账户费用，核对券商账单；入金出金不计盈亏。
- 从券商 CSV 导入交易和资金流水：自动识别中英文表头，预览、错误行和疑似重复确认后才写入。
- 使用默认收盘行情，也可以点首页或收益页的行情状态，换成 Finnhub 或自定义 API。
- 导出备份、恢复账本，或者先用示例模式看看。

目前只做美元美股和 ETF 记账，不连接券商；除手动分红与税费外，暂不处理拆股、做空和期权。

## 1.26 更新

把持仓记录补成完整账本，先管好现金。

- 收益页新增现金账本：期初余额、入金、出金、分红（毛额减税费）、账户费用；买卖自动联动现金，账户总收益 = 证券收益 + 分红净额 − 费用。
- 新增券商 CSV 导入：交易和资金流水，自动映射字段，预览错误行与疑似重复，确认后写入，重复导入不重复记账。
- 现金为可选字段，旧账本直接兼容；完整备份含现金，通用备份不含。

1.25 的今日盈亏、行情状态、交易区间筛选和记账表单改进都保留。更新内容、覆盖安装步骤和使用注意事项见 [1.26 升级说明](releases/v1.26.0.md)。

## 安装和备份

Release 里的 IPA 没有签名，需要用自己的 Apple 账号签名后安装，例如使用 Sideloadly。

**升级前先导出完整备份，再用原签名账号和应用标识覆盖安装，不要先卸载旧版。** 应用标识是 `com.personal.stockledger`。

账本不会自动同步到其他设备，卸载也会删除本机数据，记得把备份存到应用外。API 密钥不包含在账本备份里，换设备后要重新填写。

行情是否及时取决于数据源和订阅权限。最新报价用于当前估值，每日收益日历仍用收盘历史。配置方法见 [API 设置说明](API-SETTINGS.md)。

## 本地运行

项目用 TypeScript、Vite 和 Capacitor 开发。安装 Node.js 24 和 pnpm 11.19.0 后：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

浏览器里的数据与 iPhone 分开保存。iOS 安装包通过仓库的 GitHub Actions 编译，也可以在 Mac 上使用 Xcode 构建。

计算口径和旧版兼容问题，分别放在 [收益说明](DAILY-RETURNS.md) 和 [数据兼容说明](DATA-COMPATIBILITY.md)。

## 2.0 build 2 验证构建

收益页的统计、日历和曲线数据改为后台计算；报价或现金变化复用已有历史结果。

汇丰 PDF 导入入口在“设置 → 银行月结单 PDF 导入”。可以一次选择多份投资服务综合结单，核对预览后确认。支持美元股票买卖与派付分红，卖出费用关联到交易；银行编号重复时禁止添加，疑似手工记录默认不选。港币基金会显示为排除，不会混入美元账本。

投资结单不含银行入金、出金与期初现金，这些仍需根据现金账户流水填写。未披露的分红税额不会按固定税率猜测。扫描 PDF、银行往来账户结单及其他机构格式暂不支持。

覆盖安装前先导出 2.0 备份。此构建继续使用原来的 2.0 账本文件，并保留旧 2.0 备份读取能力。新增的银行交收金额用于处理小数价格的舍入；修改成交股数、单价或手续费后，改用手工交易计算口径，仅修改备注不会丢失交收信息。

原生测试在 macOS 上运行 `bash scripts/test-native.sh`，覆盖导入、保存失败、旧备份、连续更新和大账本。测试数据为虚构数据，不包含个人结单。

### build 3：收盘价与滚动修正

设置中可选“自动（休市用收盘）”“最近收盘价”或“所选接口最新报价”。固定收盘模式使用 Yahoo 完成日线；所填 API Key 用于盘中所选接口。保存后点击立即同步，页面会标明实际美东报价日期。自动刷新按保存的间隔在前台运行，选“仅手动”则不会自动发起请求。

收益页改用固定日历布局与保留的图表图层；后台计算、报价刷新编码也与滚动线程分离。构建和自动测试已经通过，流畅度仍需 iPhone 实测。
