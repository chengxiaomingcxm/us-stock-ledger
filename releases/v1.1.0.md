# 持仓账本 1.1.0

2026-09-26 最终版本，包含今天完成并验证的原生界面与收益展示修改。

发布标签为 `native-v1.1.0`。`v1.1.0` 是旧 Web 版历史标签，保留不动；两个产品线不能共用或覆盖同一标签。

## 最终收益口径

- 收益日历日期格子显示**同日收盘浮盈快照**：当天收盘仍持仓股票的市值减剩余持仓成本。比如 9 月 25 日显示 9 月 25 日的收盘浮盈，不把前一天数值挪到当天。
- 月份下方“本月收益”是**全月每日投资盈亏合计，包含当月买卖、成交价和手续费影响**，不相加每日浮盈快照。
- 日历新增“收益金额／收益百分比”切换；百分比为当日收盘浮盈除以剩余持仓成本。空仓或无有效成本基数显示 —，缺少必要收盘价显示待补。
- 日历浮盈明细只显示该日收盘仍持仓股票；首页“收益明细”仍展示完整每日投资盈亏，包含当天清仓股票贡献，并分别显示小计。
- 持仓行重新排版，分别显示持仓收益和今日涨跌，避免百分号换行和金额挤压。当天新建仓位的每日盈亏金额有效、百分比无期初基数时，仍显示 — / 有效金额。

## 兼容与安装

应用显示版本为 **1.1.0**（不显示 build 后缀）；内部构建号为 10。支持 iOS 16+，应用标识仍为 `com.personal.stockledger`，账本仍为 `Documents/ledger-v2.json`、`format: 2`。不修改用户账本，不包含用户交易或 API Key；凭据仍存 iOS Keychain。

附件 IPA **未签名**，需要自行签名。升级前先导出备份，再覆盖安装；不要先卸载旧版。
