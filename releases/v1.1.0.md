# 持仓账本 v1.1.0

适用于 iOS 16.0 或更高版本。此 IPA 未签名，需要使用你自己的 Apple 账号签名安装。

## 本次更新

- 打开 App 或返回前台时读取最近已完成交易日的美股收盘价，自动更新市值和浮动收益；支持手动刷新。
- 按纽约交易日期处理冬夏令时、提前收盘及休市，排除尚未完成的当日日线。
- 公司 Logo 随股票代码加载，失败时显示代码首字母。
- 兼容第一版 JSON 备份，继续读取第一版本机账本。
- 更新失败时保留原报价；编辑期间的迟到响应不会覆盖刚保存的数据。

## 从第一版升级

1. 在第一版的「备份」页导出 JSON，保存到 iPhone「文件」中。
2. 使用原 Apple 账号、原签名工具和相同的最终应用标识覆盖安装，**不要卸载第一版**。工程标识仍为 `com.personal.stockledger`。
3. 打开新版，核对交易笔数、持仓股数、成本及已实现收益。
4. 点击「更新收益」，查看每只股票的报价日期及失败提示。
5. 如需恢复，旧 `.json` 或误命名为 `.js` 的文件均可选择，但内容必须是 JSON，不执行脚本。

## 数据与限制

账本保存在本机，公开的工程和安装包不包含用户录入的交易。网络请求仅携带股票代码，不上传数量、金额和备注。行情来自 Yahoo Finance 公共接口，Logo 来自 Financial Modeling Prep；服务可能延迟、限流或不可用，届时保留已有数据。

本版没有每日收益历史曲线，不自动录入分红、拆股或券商交易。自动更新在打开或返回 App 时执行，不是后台定点任务。

39 项计算与兼容性测试、4 项浏览器流程测试已通过；云端真机 ARM64 编译及 IPA 完整性验证通过。本次升级的 iPhone 覆盖安装与原生网络行为仍需用户核对。
