# 持仓账本 1.0.1 build 7

这是本项目的最终版本。在 1.0.1 build 6 的基础上修复两个高优先级问题，不新增功能，不改变账本格式或收益口径。

## 修复

- CSV 和汇丰 PDF 导入选择“插入同日记录之前”时，保留新导入批次的原始买卖顺序，避免移动平均成本和已实现收益被错算。
- 点击导出备份时现场序列化当前账本，恢复一份记录数量相同的备份后，不再导出恢复前的旧内容。

本版不会自动重排已经写入账本的历史记录。如果曾使用“插入同日之前”导入多笔同日交易，请先备份，再按原始凭据核对顺序。

## 版本与兼容性

- 版本：1.0.1（build 7）
- 应用标识：`com.personal.stockledger`
- 最低系统：iOS 16.0
- 账本文件：`Documents/ledger-v2.json`
- 数据格式：format 2
- 密钥仍保存在 iOS Keychain

可从 1.0.0 或 1.0.1 build 6 覆盖安装。安装前建议在旧版中导出账本备份，不要先卸载应用。
