# 持仓账本 1.0.1（原生版）

Portfolio Polish：**不改收益口径，不新增交易功能**，重点在首次体验、错误可读性与工程闭环。

## Highlights

- **示例模式（Demo Mode）**：设置里一键载入一套完整示例账本（买卖、分红、费用、期初余额），不用导入任何文件就能看到全部界面。示例与真实账本**完全隔离**，退出示例不会动你的数据——旧版「示例账本」会直接覆盖真实账本，这是本版最重要的修正。
- **错误处理重做**：失败时给可读的中文／英文说明，系统原始报错只写进本机诊断日志，不再直接丢给用户；导出失败此前会静默无提示，现在会明确报错。
- **修掉收益页在 320px 宽度下的横向溢出**：现金汇总格此前只剩 0.28px 余量，换一套字体度量就会把整页顶宽（Linux 上实测必现）。已改为可收缩布局，窄屏不再横向滚动。
- **设置重新分组**：显示 / 行情数据 / 数据 / 支持 四组，每个入口一个二级页面，二级页沿用同一套设计语言；「账本信息」只读，不提供清空或删除账本的操作。

## Improvements

- 补齐错误提示缺失的英文文案 61 条；另有 15 条因把数值拼进翻译查找键、导致永远匹配不到译文，改为占位符形式。
- 收益页现金汇总格改用 `minmax(0,1fr)`，宽屏视觉不变（实测 360 / 402px 下列宽与修改前完全一致）。
- 截图与日历渲染链路加了守卫：截图缺失、体积异常或没有真实数据（`days=0` / `months=0`）都会让构建失败，空态截图不能再混进文档。
- 图表图层按 `revision` 比对复用，避免每次刷新重建曲线图层。
- 首页改用导航栏 `+` 添加交易，移除旧的悬浮按钮（FAB），窄屏下不再遮挡内容。
- 英文界面收尾：翻译表补齐到 536 条，英文界面不再出现中文说明。
- 明确 1.0 的数据基线：账本格式 `format: 2`；1.0 之前的测试版与旧 Web 版不再是兼容目标，`note` 字段只保存原文。

## Demo Mode

**设置 → 支持 → 示例** 进入，**退出示例模式** 退出。示例使用独立的派生状态，`ledger-v2.json` 全程不被写入。建议先看示例确认界面与口径，再录自己的数据。

## Testing

- 单元测试 **148 项**（13 个文件）；
- 原生 Swift 套件 **413 条断言**，含 25,000 收盘价 / 4,000 交易日 / 1,000 笔交易的负载测试，并新增 CSV 导入与错误路径用例；
- Playwright 端到端 **26 项**，含 320 / 402 / 430px 三档宽度无横向溢出；
- 模拟器日历渲染与 6 张界面截图渲染，均有非空 / 非空数据守卫；
- 两个 CI 工作流全部通过：`checks`（ubuntu，约 1 分钟）与 `build-ios`（macOS，单测 → 原生测试 → 模拟器渲染 → 未签名 IPA，约 14–18 分钟）。

## Known Limitations

- 仅美元美股与 ETF，不做多币种换算；
- 不支持期权、期货、做空；
- 不连接券商同步，成交来自手动录入或结单导入；
- 不自动处理公司行动（拆股需手动录入）；
- 行情以日线收盘为主，不是实时行情流；
- 仅支持 iOS 16+；
- 未签名 IPA，需自行用 Sideloadly / AltStore 以自己的 Apple ID 签名安装。

## 安装

下载 `StockLedger-1.0.1-unsigned.ipa`，用 Sideloadly / AltStore 以自己的 Apple ID 签名安装。**覆盖安装，不要先卸载旧版**；安装前先在旧版导出备份。

应用标识仍为 `com.personal.stockledger`，账本文件、密钥保存位置与数据结构沿用 1.0.0，覆盖安装即可升级。

## 校验

- SHA-256：见同目录 `v1.0.1.json` 或 Release 附件。
- 构建产物：未签名 IPA（arm64，iOS 16+）。

## 升级前

1. 在旧版导出账本备份，保存到应用之外。
2. 用同一 Apple ID 和应用标识覆盖安装。
3. 打开后核对持仓、现金与外观设置；必要时从备份恢复。
