# 持仓账本 1.22 升级说明

界面版本 1.22；内部版本 1.22.0，build 5。

## 本次更新

- 底部操作栏改为「持仓｜交易｜记一笔｜收益｜设置」，中央按钮直接打开交易表单。

- 首页采用浅灰背景、白色圆角卡片与蓝色操作按钮：突出持有收益和市值，下方为收益概览及紧凑持仓列表，保留玻璃风格底部导航。
- 眼睛按钮可隐藏首页和持仓详情的金额、数量与收益率；交易和收益页不受此开关影响。
- 新增全部 / 盈利 / 亏损 / 待报价筛选，以及代码 / 市值 / 收益排序。点股票打开持仓详情，点报价日期更新价格。
- 长篇说明集中到「设置 → 帮助文档」，随应用打包、离线可用；API 表单可直接打开配置帮助。
- 首页仅保留一行行情状态，详细状态按需点开，失败提示、缺失报价与实际报价日期继续显示。

大号持有收益是持仓浮动收益，不是今日收益。此次更新保持交易、成本计算、行情接口、账本存储位置及备份格式不变。

## 安装

1. 在旧版导出完整备份并存到应用外。
2. 使用原签名账号和 `com.personal.stockledger` 应用身份签名 IPA，直接覆盖安装，**不要先卸载旧版**。
3. 打开后核对持仓、交易笔数及 API 设置。

59 项单元测试、11 项浏览器流程通过；手机与桌面尺寸检查无横向溢出。iPhone 17 真机手势、键盘与覆盖安装仍需实际安装确认。IPA 未签名，需要自行签名安装。
