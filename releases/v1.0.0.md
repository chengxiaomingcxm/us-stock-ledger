# 持仓账本 1.0.0（原生版）

## 这是一次界面重写

原生版把界面从 WebView 换成 SwiftUI，功能与旧 Web 版对齐，数据保存在 iPhone 本机。应用标识仍为 `com.personal.stockledger`，覆盖安装可沿用旧原生测试版账本；旧 Web 版 1.26 及更早版本的账本不会自动迁移。

## 主要功能

- 美元美股、ETF 的买卖、手续费和备注；持仓成本按移动平均计算。
- 今日盈亏对照上一交易日收盘；缺少行情显示「待补全」，不以零代替。
- 现金账本：期初余额、入金、出金、分红（含税费）与账户费用，买卖联动现金。
- 每日收益日历与累计收益曲线。
- 行情：Yahoo 日线收盘、Finnhub 或自定义 HTTPS 接口，API Key 存系统钥匙串。
- 导入券商 CSV（成交明细 / 资金流水）与汇丰投资结单 PDF，先预览核对再写入。
- 本地 JSON 备份与恢复，超过 30 天未备份有提醒。
- 中文 / English 界面一键切换。
- 深浅色、红涨绿跌／绿涨红跌、动态字体与 VoiceOver。

## 安装

下载 `StockLedger-1.0.0-unsigned.ipa`，用 Sideloadly / AltStore 以自己的 Apple ID 签名安装。**覆盖安装，不要先卸载旧版**；安装前先在旧版导出备份。

## 校验

- SHA-256：见同目录 `v1.0.0.json` 或 Release 附件。
- 构建产物：未签名 IPA（arm64，iOS 16+）。

## 升级前

1. 在旧版导出账本备份，保存到应用之外。
2. 用同一 Apple ID 和应用标识覆盖安装。
3. 打开后核对持仓、现金与外观设置；必要时从备份恢复。
