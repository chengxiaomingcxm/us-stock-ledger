# 持仓账本 1.2.0（build 3）

## 新增功能

- 每日收益日历：查看每日美元收益，点选日期查看各股票贡献；当天买卖及手续费纳入计算。
- 收盘累计收益曲线：尝试补齐近三个月行情并在本机保留历史，交易修改后自动重算。
- 同步状态：显示最近日历确认时间、已记录日期、各股报价日期和待同步提示；缺失数据标明待补全或未确认。
- 本机恢复记录：编辑、删除、修改报价、导入及恢复之前自动保护当前账本，最多保留 5 份、总计 8 MB。
- 两种导出：完整备份保留收益历史；通用备份保留各版本均能使用的交易、报价和备注。

## 升级与数据保留

1. 先在旧版导出备份并保存到“文件”。不要卸载旧 App。
2. 下载本 Release 的 unsigned.ipa，以之前相同的 Apple 账号和应用标识签名覆盖安装。
3. 打开后核对交易笔数、持仓股数、成本和已实现收益，再点击“更新收益”。
4. 到“收益”页查看日历，首次联网尝试补齐近三个月；缺少数据的日期留空并说明原因。
5. 导出一份新版完整备份。若回旧版使用，另导出通用备份，并保留这份完整备份。

继续兼容 v1.0 / v1.1 本机账本及 JSON 内容的 `.json` / `.js` 文件。应用标识、核心文件版本与成本算法未变。旧版可以读取新版的核心交易与报价，但旧版再次导出会丢弃收益历史；各版本通用不代表旧版能保存新增功能数据。

## 验证与范围

- 52 项单元测试，包含真实旧版解析器兼容、现金流计算、历史重算、缺失报价和恢复失败保护。
- 5 项浏览器流程，包含原数据升级、收益日历、完整/通用导出、本机恢复及迟到网络响应保护。
- TypeScript 检查、生产构建和 iOS 工程同步通过。IPA 通过云端 Xcode 编译及版本、架构、资源校验后发布。
- IPA 未签名，需自行签名安装；尚未在用户 iPhone 上测试本次覆盖安装与原生文件分享。
- 不含分红、拆股记账、券商交易同步或后台定时任务。公共行情可能延迟或失败；详情见仓库 DAILY-RETURNS.md 和 DATA-COMPATIBILITY.md。
