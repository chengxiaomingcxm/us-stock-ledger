# 持仓账本 1.2.0

本版本包含现金分红二级页面与汇丰新版月结单解析修复。

## 更新内容

- 现金分红按股票代码分组；每组可折叠，显示该股票分红净额与笔数。未关联股票的记录也会保留。
- 展开后可查看每笔分红日期、净到账金额、已知预扣税费；支持新增、编辑和删除。汇丰月结单未披露的税额继续明确标为未知。
- 主页不再逐条展开现金分红，减少长列表；分红汇总行可进入记录页。
- 汇丰投资结单新版分页：交易行跨页时继承前页股票代码和证券类别；交收金额与计算值相差不超过 $0.02 时以银行交收额为准，超出范围仍阻止确认。

## 版本与兼容

- 应用显示版本：**1.2.0**；内部构建号：11；iOS 16+；Bundle ID：`com.personal.stockledger`。
- 数据文件仍为 `Documents/ledger-v2.json`，账本格式仍为 `format: 2`，无需升级或迁移账本。
- IPA 为未签名个人安装包。安装前先导出备份，并覆盖安装旧版；不要先卸载，以免丢失本机账本。
