# 持仓账本 1.21 升级说明

界面版本 1.21；安装包内部版本 1.21.0，build 4。

## 更新内容

- 液态玻璃风格浮动导航、半透明控件、圆角弹窗；加强文字可读性及手机安全区适配。
- 修复双击导致页面缩放的问题：触控手势限制、显式关闭 iOS WebView 缩放、输入控件至少 16px。
- 「设置 → 行情 API 设置」可选择 Yahoo 收盘价、Finnhub 最新报价或自定义 HTTPS 接口，填写密钥、测试连接和设置前台刷新间隔。
- 最新报价与收盘历史分开，接口失败保留上次报价，按实际报价时间显示；盘中价格不混入每日收益。
- 保留交易、成本算法、原本机账本、备份与恢复功能。

## 覆盖安装

1. 在旧版导出完整备份并保存到应用外。
2. 使用原签名账号和应用身份签名 IPA，保持 `com.personal.stockledger`，直接覆盖安装，**不要先卸载旧版**。
3. 打开后核对交易笔数、持仓成本和历史收益，再到设置中配置自己的 API。

API Key 不随账本备份导出。自定义接口须符合 [API 配置指南](https://github.com/chengxiaomingcxm/us-stock-ledger/blob/main/API-SETTINGS.md)，并非任意供应商的 URL 都能直接使用。行情及时性取决于服务商权限；日历仍使用 Yahoo 收盘历史。此版本使用 WebView 实现玻璃风格，真机手势与 iOS 27 系统行为仍需实际安装确认。

IPA 未签名，需要自行签名后安装。SHA-256 文件用于核对下载完整性。
