# 持仓账本 1.0.2 build 8

修复历史日线缺口导致收益日历反复显示“缺少收盘价”的问题。

- 同步历史时，Yahoo 某日收盘价为空才向 Nasdaq 查询该股票、该日期的日收盘价；已有的 Yahoo 数据优先保留。
- 手动“同步行情”现在也会同步历史。早上打开 App 后点一次即可更新上一交易日的持仓报价和收益日历。前台定时刷新仍只更新报价。
- 已补齐的上一收盘价不会被后续自动报价刷新中的旧基准覆盖。
- 备用接口失败或没有明确的同日收盘价时，仍显示待补全，不用盘中价或零价代替。

版本 1.0.2（build 8），支持 iOS 16+。应用标识 `com.personal.stockledger`、`Documents/ledger-v2.json`、账本 format 2 和 Keychain 键均不变。可以覆盖安装；安装前建议导出账本备份，不要先卸载旧版。

IPA 未签名，需要自行签名安装。构建记录与 SHA-256 待本轮 Actions 完成后补入。
