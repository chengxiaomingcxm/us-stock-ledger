# 持仓账本 1.25 升级说明

界面版本 1.25；内部版本 1.25.0，build 8。

## 本次更新

- **首页区分今日盈亏与持有收益。** 大号数字改为今日盈亏：结合上一交易日收盘、当前价格、当天买卖和手续费计算；持有收益（浮动盈亏）移到下方“持有收益”卡片。缺少必要行情时显示待补全，不以零代替；休市日按最近收盘比较。
- **行情状态更完整。** 首页行情状态标注美股休市 / 交易日；行情状态面板逐只显示报价日期、时间、来源与类型（最新报价 / 美股收盘 / 手动报价），休市与报价过期分开提示。刷新失败保留已有价格并提示原因。
- **交易查询增加日期区间。** 交易页可按起止日期、买卖类型和关键字组合筛选，并汇总范围内的笔数、股数、手续费与已实现收益。
- **记账表单更好用。** 打开自动聚焦股票代码，保存按钮滚动时保持可见；未保存时关闭表单会提醒确认。
- **首页与持仓详情调整。** 首页大卡片变矮，首屏更早看到持仓列表；金额等宽数字显示。点股票进入详情，集中查看股数、成本、今日盈亏、报价状态与最近相关交易。

此次更新新增今日盈亏计算；原有交易成本计算、行情获取、账本存储位置及备份格式保持兼容；最新价格仍只用于当前估值与今日盈亏，不写入收益日历或备份。

## 安装

1. 在旧版导出完整备份并存到应用外。
2. 使用原签名账号和 `com.personal.stockledger` 应用身份签名 IPA，直接覆盖安装，**不要先卸载旧版**。
3. 打开后核对持仓、交易笔数、成本、外观与行情来源设置。

## 使用时留意

- 新交易和手动报价默认使用美东日期；旧记录不自动迁移日期，异常记录需核对后手动编辑。
- 日历必须确认上一交易日；收盘后须取得对应个股历史收盘价。发现拆股时暂停受影响收益计算。休市日忽略盘后报价变化，休市交易记录提示核对。

- **今日盈亏 ≠ 持有收益。** 今日盈亏按上一交易日收盘算今天的变动；持有收益是买入至今的全部浮动盈亏。盘中可使用当天最新报价；收盘确认后需要对应个股收盘价，缺少必要行情时显示待补全。
- **休市不是报价过期。** 周末和假日显示“美股休市”，此时最新报价与最近收盘相同属正常；只有超过 15 分钟未更新的最新报价、早于最近交易日或超过 4 天的收盘价才会提示较早。
- **区间汇总的口径。** 已实现收益为范围内卖出记录的收益之和（卖出金额减手续费减移动平均成本），与持仓页的累计口径一致。
- **未保存提醒。** 填写交易或股价表单后直接关闭会先询问；确认放弃才关闭，避免误触丢失输入。
- **最新报价只在前台刷新。** 价格是否及时取决于供应商和账户权限，失败时保留已有报价，请留意每只股票的实际报价时间。
- 外观、涨跌颜色和备份提醒仍在「设置 → 显示与提醒」；“记一笔”仍在底栏中央。玻璃外观由 WebView 界面实现，不是 SwiftUI 原生 Liquid Glass。
