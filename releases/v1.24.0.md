# 持仓账本 1.24 升级说明

界面版本 1.24；内部版本 1.24.0，build 7。

## 本次更新

- 行情来源入口从设置页移到首页 / 收益页的「行情状态」面板：点顶部行情状态 → 更换行情来源，即可选择 Yahoo / Finnhub / 自定义 API。设置页不再单独放行情 API 入口。
- 修复收益页月份选择器在 320px 窄屏下的横向溢出。
- 设置页更简洁，只保留帮助文档、显示与提醒、备份与恢复。

此次更新保持交易、成本计算、行情算法、账本存储位置及备份格式不变。

## 安装

1. 在旧版导出完整备份并存到应用外。
2. 使用原签名账号和 `com.personal.stockledger` 应用身份签名 IPA，直接覆盖安装，**不要先卸载旧版**。
3. 打开后核对持仓、交易笔数、外观与行情来源设置。

65 项单元测试、13 项浏览器流程通过；深浅色各页在 320 / 402 / 430 像素宽度无横向溢出。IPA 未签名，需要自行签名安装。
