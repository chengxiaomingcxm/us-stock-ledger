# 持仓账本 1.24 升级说明

界面版本 1.24；内部版本 1.24.0，build 7。

## 本次更新

- 行情来源入口从设置页移到首页 / 收益页的「行情状态」面板：点顶部行情状态 → 更换行情来源，即可选择 Yahoo / Finnhub / 自定义 API。设置页不再单独放行情 API 入口。
- 修复收益页月份选择器在 320px 窄屏下的横向溢出。
- 设置页更简洁，只保留帮助文档、显示与提醒、备份与恢复。

此次更新保持交易、成本计算、行情算法、账本存储位置及备份格式不变。

## 安装

1. 在旧版导出完整备份并存到应用外。
2. 使用原签名账号和 `com.personal.stockledger` 应用身份签名 IPA，直接覆盖安装，**不要先卸载旧版**。
3. 打开后核对持仓、交易笔数、外观与行情来源设置。

## 使用时留意

- **行情入口换了位置。** 在首页或收益页点「行情状态 → 更换行情来源」，可切换 Yahoo、Finnhub 或自定义 API；设置页不再单独显示该入口。
- **更新频率不等于实时行情。** 价格是否及时取决于供应商和账户权限。最新报价只在前台刷新，失败时保留已有报价，请留意每只股票的实际报价时间。
- **持有收益不是今日盈亏。** 首页的大号收益是当前持仓浮动收益；每日收益日历和历史曲线使用收盘历史。更换最新报价来源不会同时更换历史数据源。
- **密钥不随账本备份导出。** iOS 使用系统钥匙串；从较早版本升级时会迁移旧配置。换设备需重新填写密钥；切换供应商会清空密钥输入，需要填写对应服务的密钥。
- **自定义 API 有固定格式。** 接口地址须使用 HTTPS、包含 `{symbol}`，返回应用要求的 JSON；不是任意第三方 API 地址都能直接使用。具体见 [API 设置说明](https://github.com/chengxiaomingcxm/us-stock-ledger/blob/main/API-SETTINGS.md)。
- **备份提醒不会自动备份。** 导出后请确认文件已保存到应用外；本机恢复记录和系统分享窗口都不能替代一份实际保存的备份。
- 外观、涨跌颜色和备份提醒仍在「设置 → 显示与提醒」；“记一笔”仍在底栏中央。玻璃外观由 WebView 界面实现，不是 SwiftUI 原生 Liquid Glass。

## 升级后核对

打开应用后核对交易笔数、持仓数量和成本，再检查外观、涨跌颜色及行情来源。若发现数据异常，先保留当前数据与原备份，避免反复卸载或覆盖导入。
