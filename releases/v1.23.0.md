# 持仓账本 1.23 升级说明

界面版本 1.23；内部版本 1.23.0，build 6。

## 本次更新

- 「设置」新增「显示与提醒」：外观可选跟随系统、浅色或深色；涨跌颜色可选绿涨红跌或红涨绿跌；备份提醒可选每 7 天、每 30 天或关闭。选择会保存在本机，重启后继续生效。
- 行情 API 密钥在 iOS 上改存系统钥匙串，不再写入账本备份；旧位置保存的密钥会在首次使用时自动迁移，写入会先校验再清理旧值。
- 交易表单新增「一半 / 全部」快捷卖出，卖出时可一键填入当前持仓的一半或全部股数；股票代码提供最近使用下拉，手续费默认沿用上一笔交易。
- 保存买入或卖出后，首页会短暂显示「撤销新增」，可删除刚才这笔交易并重新计算收益。
- 首页在需要备份时显示「该备份账本了」提醒，点击直接前往设置。

此次更新保持交易、成本计算、收盘行情接口、账本存储位置及备份格式不变。

## 安装

1. 在旧版导出完整备份并存到应用外。
2. 使用原签名账号和 `com.personal.stockledger` 应用身份签名 IPA，直接覆盖安装，**不要先卸载旧版**。
3. 打开后核对持仓、交易笔数、外观与行情 API 设置。

65 项单元测试、13 项浏览器流程通过；深浅色各页在 320 / 402 / 430 像素宽度无横向溢出。iPhone 真机手势、键盘与覆盖安装仍需实际安装确认。IPA 未签名，需要自行签名安装。
