# 持仓账本 1.0.2 build 9

这一版把历史收盘价改为多层兜底，解决单一免费来源缺数时反复刷新仍无法补全收益的问题。

- 在「设置 → 行情数据 → 行情来源 → API 设置」可填写自己的 Tiingo 日线 Key。填写后 Tiingo 为主来源，Yahoo 为备用，Yahoo 明确为空的日期继续由 Nasdaq 补缺。
- 每次手动“同步行情”会同时更新报价和历史收盘；任一来源失败都保留账本中已有价格，不写入零价。
- 所有来源仍缺数据时，点收益日历中的缺失日期，可在详情手工补录。只接受账本已有股票和日历已有交易日；手工值优先于之后的自动同步，也可重新录入修正。
- Tiingo、Finnhub 和自定义接口凭据都只保存在 iOS Keychain，不进入 `ledger-v2.json` 或备份。

版本 1.0.2（build 9），支持 iOS 16+。应用标识 `com.personal.stockledger`、`Documents/ledger-v2.json` 和账本 format 2 均不变，可以覆盖安装。安装前建议导出账本备份，不要先卸载旧版。

IPA 未签名，需要自行签名安装。
