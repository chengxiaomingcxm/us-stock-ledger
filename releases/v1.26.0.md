# 持仓账本 1.26 升级说明

界面版本 1.26；内部版本 1.26.0，build 9。

## 本次更新

- **现金账本。** 收益页新增「现金账本」：先设置期初余额，再记录入金、出金、手动分红（含预扣税费）和账户费用。期初日之后的买卖自动联动现金（买入扣含费支出、卖出加扣费收入），总资产 = 现金余额 + 持仓市值。
- **入金出金不计盈亏。** 买卖是资产转换，同样不计盈亏；收益页新增「账户总收益」= 证券累计收益 + 分红净额 − 账户费用，今日盈亏和收益日历仍只统计证券。
- **券商 CSV 导入。** 设置页或现金账本点「导入 CSV」，支持 UTF-8 / BOM / UTF-16 / GBK 编码，逗号、分号或制表符分隔，中英文列名均可。导入前展示字段映射、逐行预览、错误行、疑似重复与已导入判定（券商编号 / 流水编号），确认后才写入；重复导入不会重复记账。
- **可追溯。** CSV 导入的交易在列表带 CSV 标记，现金记录也标注来源；编辑、删除和导入前都会先写本机恢复记录，失败不覆盖可用账本。

## 数据与迁移

- 现金记录是账本中的可选字段：1.25 及更早版本的账本和备份可直接读取，无需任何迁移操作，交易、成本与已实现收益保持不变。
- 旧账本没有现金记录，无法推断真实账户现金余额，请对照券商账单手动设置期初余额，再补记之后的资金流水。
- 期初余额是“期初日期当天开始前”的现金；之前的交易和资金流水视为已包含在期初余额中，仅保留备查、不重复计入。修改期初日期会重新划定边界。期初允许为零，不支持负数。
- 完整备份包含现金记录与历史行情；通用备份不含，导出前会提示将剔除的数据。1.25 及更早版本打开 1.26 备份时会忽略现金字段，重新导出后不会保留，请在两台 1.26 设备之间使用完整备份。

## 安装

1. 在旧版导出完整备份并存到应用外。
2. 使用原签名账号和 `com.personal.stockledger` 应用身份签名 IPA，直接覆盖安装，**不要先卸载旧版**。
3. 打开后核对交易笔数、持仓数量、成本、外观与行情来源设置，再到收益页设置期初余额。

## 使用时留意

- 期初余额是开始用账本前账户里已有的现金，只设置一次；之后入金、出金、分红、费用和股票买卖都会累加或扣减到余额上。
- 分红金额填毛额，预扣税费另填；到账金额 = 毛额 − 税费，请与券商账单核对。只有分红记录可以填写税费，只有分红和费用记录可以关联股票。
- CSV 第一行必须是表头；列名无法自动识别时，在「字段映射」里手动指定每列的含义。日期接受 2026-09-16、2026/09/16 或 09/16/2026，可带合法时间（美东，仅用于同日排序）；金额仅支持美元，非美元币种整行拒绝；千位分隔符只能按三位分组。
- 有券商编号 / 流水编号的记录以编号判断是否已导入，已导入不可重复写入；没有编号而数值相同的行标为疑似重复、默认不勾选。编辑导入记录会保留编号，重新导入不重复入账。
- 日期可带美东本地时间（如 09:30:00），用于同日排序；不支持带时区后缀（Z / 偏移），避免静默改错日期。同一天既有买又有卖且时间不全时需勾选确认顺序；账本已有同日交易时可选择追加或插入到已有交易之前。
- 导入卖出记录时会整体校验持仓，超卖等错误在预览即提示，确认后仍失败时账本不变。
- 账户总收益 = 证券累计收益 + 分红净额 − 账户费用（全历史）；修改现金期初不会移除已记录的分红收益。
- 具体券商的真实 CSV 格式尚未用实际导出文件核对，导入前请先用小样本预览确认。
- 现金账本位于收益页「累计投资收益」卡片下方；设置页「备份与恢复」里也有 CSV 导入入口。示例模式只展示虚构现金数据，不能编辑或导入。
