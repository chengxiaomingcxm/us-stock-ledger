# 每日收益计算与行情边界

## 计算

每日美元收益 = 当日结束持仓 × 当日收盘价 − 当日开始持仓 × 前一交易日收盘价 + 当日卖出扣费收入 − 当日买入含费支出。

例如原来无持仓，当天买入 10 股、单价 100、手续费 1，收盘 110：收益为 1,100 − 1,001 = 99 美元。次日不交易而收盘 120：日收益为 100 美元。新增本金不会被算成收益。同日开仓清仓无需收盘价；清仓当天无需该股票的当日收盘价。

曲线显示各日收盘累计投资收益 = 当日结束持仓市值 + 截至当日所有卖出净收入 − 所有买入含费支出。它不是收益率、账户现金余额或税务收益。历史编辑、删除和恢复会从当前交易重新计算，不保存容易过时的收益数字。

缺少必要行情时不以 0 代替：日历显示“待补全”，该日不参与月度已记录收益合计。缺少前日行情但当日收盘完整时，当日累计值仍可能有效。未确认日期不参与合计。月合计只涵盖已记录完整日，不保证覆盖整月。

## 行情与日期

- 启动或回前台检查，自动请求间隔至少 15 分钟；可手动刷新，无服务器、不承诺后台定时更新。
- Yahoo Finance chart 请求近三个月、1d 日线、排除盘后、请求拆股事件。使用 quote.close，不用 adjclose。校验股票代码、USD、美东时区、美股/ETF 类型，剔除无效价格。
- 当日收盘必须在服务返回的正常交易时段结束至少 15 分钟后才采用，适配提前收盘和夏令时。价格来源可能仍修订；后续同步覆盖同股票同日期的旧值。
- 使用 SPY 已完成日线日期作为交易日参考，不将某一持仓缺失的日期当成休市。SPY 失败时保留已保存日历，显示错误。零持仓但近期卖出后仍会请求相关股票和日历。
- 首次尝试补齐近三个月，以后保留已有历史。较早交易不会自动获得全历史行情；缺失的日期不会编造收益。手动当前报价用于当前估值，不覆盖历史收盘价。
- 星期六、星期日及已公布的 2026–2028 NYSE 假日显示休市；其他缺失工作日显示未确认。相邻历史记录之间存在非已知休市缺口时，不把多日变化冒充一日收益。
- 假日来源：[NYSE 官方交易时间与日历](https://www.nyse.com/trade/hours-calendars)，核对日期 2026-09-15。此静态假日表需在未来版本维护；未知年份的缺口按未确认处理。
- 交易日期应录美东实际成交日，避免亚洲日期导致现金流错位。相邻确认交易日之间出现交易记录时，受影响日提示核对日期。

## 拆股与服务限制

v1.2 不支持分红、拆股记账和股数自动调整。Yahoo 历史 close 可能因拆股修订；如果同步返回持有期间的拆股事件，保守暂停该股票相关历史日收益与累计曲线，提示核对股数和成本。事件只在服务返回范围内可见，不能保证发现更早的公司行为；当前持仓页继续原算法，用户需自行核对。ETF 分配和公司分红也不计入收益。

公共行情与 Logo 服务可能限流、变更或停止提供。失败保留已保存数据及日期，不清零。新增 SPY 请求只发送代码；交易数量、金额、备注和备份不上传。浏览器预览可能受 CORS 限制；iOS 使用原生 HTTP 请求。

## 1.21 最新报价

Finnhub 或自定义 API 只影响当前持仓市值、浮动收益及累计投资收益。每日收益日历、收盘累计曲线和交易日历仍使用 Yahoo Finance 已完成日线。两者时点不同，不能将当前估值与收盘日收益直接视为同一个数值。最新报价不会写入 history，也不会覆盖同日手动报价或日期更晚的已保存报价。
